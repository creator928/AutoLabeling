# AutoLabeler

AutoLabeler는 이미지 라벨링, 학습 데이터셋 생성, YOLO 학습, 학습 결과 기반 오토 라벨링까지 하나의 GUI에서 수행할 수 있도록 만든 Windows용 도구입니다.  
단순 박스 어노테이션 툴이 아니라, 사람이 직접 초기 데이터를 검토하고 그 결과를 바탕으로 모델을 학습시킨 뒤 나머지 이미지에 자동 라벨을 확장하는 반자동 데이터 제작 흐름을 목표로 설계되었습니다.

## 주요 기능

- YOLO 형식 `.txt` 라벨 파일 읽기 및 저장
- 박스 추가, 이동, 리사이즈, 삭제
- 이미지 일부를 검은색으로 덮는 마스킹 기능
- 이미지별 작업 상태 관리
- 지정한 수량만큼 학습용 `Temp` 데이터셋 자동 생성
- 백그라운드 YOLO 학습 실행
- 학습 결과 `result.pt`, `result.onnx` 생성
- 학습 결과 기반 오토 라벨링 실행
- 학습 결과 검증용 이미지 확인
- GPU 사용 가능 여부 자동 감지 및 CPU fallback

## 프로그램 흐름

이 프로그램은 다음과 같은 작업 순서를 전제로 합니다.

1. 작업 폴더를 선택합니다.
2. `classes.txt`가 없으면 클래스 목록을 입력해 생성합니다.
3. 앞부분 이미지들을 사람이 직접 검토하고 라벨링합니다.
4. 지정한 데이터 수량만큼 학습용 데이터셋을 자동 구성합니다.
5. YOLO 학습을 실행합니다.
6. 학습 결과를 이용해 뒤쪽 이미지에 자동 라벨링을 수행합니다.
7. 결과를 다시 검토하며 데이터셋 품질을 높입니다.

## 저장소 구성

- `Code/`
  AutoLabeler 실행 코드와 학습/추론 러너 스크립트가 들어 있습니다.
- `Document/`
  프로젝트 개요, 요구사항, 아키텍처, 실행 방법, 의존성 설치 가이드가 들어 있습니다.
- `Data/settings.json`
  앱 UI와 런타임 기본 설정 파일입니다.
- `Work/ExampleDataset/`
  프로그램 구조와 예제 라벨 파일을 빠르게 확인할 수 있는 최소 예제 데이터셋입니다.
- `install_dependency.bat`
  Windows에서 의존성 설치를 한 번에 실행하는 배치 파일입니다.

## 권장 환경

- Windows 10/11
- Python 3.10 이상
- GPU 학습 사용 시 CUDA 지원 PyTorch 환경

## 설치

기본 CPU 환경 설치:

```bat
install_dependency.bat
```

GPU 학습 환경 설치:

```bat
install_dependency.bat gpu
```

수동 설치가 필요하면 아래 문서를 참고하면 됩니다.

## 기본 사용 방법

1. 프로그램 실행 후 작업 폴더를 선택합니다.
2. 작업 폴더에 `classes.txt`가 없으면 클래스 이름을 입력합니다.
3. 이미지 목록을 순서대로 보면서 박스를 추가하거나 수정합니다.
4. 객체가 없는 이미지는 검토 완료 상태로 표시합니다.
5. 충분한 수량이 검토되면 백그라운드 학습을 실행합니다.
6. 학습 완료 후 오토 라벨링을 실행해 나머지 이미지에 라벨을 확장합니다.
7. 검증 및 재검토를 반복하며 데이터셋 품질을 높입니다.

## 기본 단축키

- `W`: 박스 그리기 모드
- `X`: 마스킹 모드
- `E`: 편집 모드
- `Q`: 현재 작업 모드 취소
- `A`: 이전 이미지
- `D`: 다음 이미지
- `S`: 화면 맞춤
- `R`: 마지막 박스 삭제
- `T`: 라이트/다크 테마 전환
- `` ` ``, `1` ~ `9`: 클래스 선택
