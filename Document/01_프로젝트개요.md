# AutoLabeler 프로젝트 개요

## 1. 프로그램 목적
AutoLabeler는 다량의 이미지 데이터셋에 대해 사람이 직접 YOLO 형식의 바운딩 박스를 빠르게 지정하고, 필요 시 부정확한 영역을 마스킹하여 학습 품질을 높일 수 있도록 설계된 데스크톱 라벨링 도구입니다.

## 2. 핵심 사용 시나리오
1. 사용자는 `Work` 디렉토리에 작업할 이미지 폴더를 넣습니다.
2. 프로그램에서 작업 폴더를 선택합니다.
3. `classes.txt`가 없다면 클래스 목록을 입력해 생성합니다.
4. 이미지 목록을 순서대로 보면서 박스를 그리고 라벨을 저장합니다.
5. 필요하면 마스킹 기능으로 노이즈 영역을 검게 처리합니다.
6. 결과물은 이미지와 같은 이름의 YOLO 라벨 `.txt` 파일로 저장됩니다.

## 3. 설계 방향
- PyQt 기반의 데스크톱 UI
- 회색조 머테리얼 스타일의 라이트/다크 모드 지원
- UTF-8 기반 한글 환경을 기본값으로 사용
- 실행 시 폴더/설정/모델을 자동 검사하는 부트스트랩 구조
- 수동 라벨링을 우선 완성하고, 자동 라벨링은 이후 확장 가능 구조로 분리

## 4. 현재 구현 범위
- 기본 디렉토리 및 설정 파일 자동 생성
- YOLO 모델 존재 검사 및 다운로드 안내
- 작업 폴더 선택 및 `classes.txt` 생성
- 이미지 목록 로딩 및 탐색
- 바운딩 박스 그리기 / 삭제 / 저장
- 마스킹 사각형 적용 및 확인 팝업
- 단축키 변경 다이얼로그
- 라이트/다크 테마 전환

## 5. 다음 확장 후보
- YOLO 모델을 활용한 자동 제안 박스 생성
- 박스 이동/리사이즈 편집
- 클래스별 통계와 작업 진행률 표시
- undo/redo 스택 강화
- EXE 패키징 및 자동 업데이트
