# AutoLabeler 실행 가이드

## 1. 권장 환경
- Python 3.10 이상
- Windows 10/11

## 2. 설치
가장 간단한 방법은 프로젝트 루트의 배치 파일을 실행하는 것입니다.

```bat
install_dependency.bat
```

GPU 학습 환경까지 한 번에 설치하려면 아래처럼 실행합니다.

```bat
install_dependency.bat gpu
```

수동 설치가 필요하면 `Code` 디렉토리에서 아래 명령으로 기본 의존성을 설치합니다.

```powershell
pip install -r requirements.txt
```

GPU 학습까지 사용할 경우에는 [05_의존성설치가이드.md](C:\Users\creat\OneDrive\바탕 화면\LabelingProject\AutoLabeler\Document\05_의존성설치가이드.md)를 함께 참고합니다.

## 3. 실행
`Code` 디렉토리에서 아래 명령으로 실행합니다.

```powershell
python main.py
```

## 4. 첫 실행 동작
- `Data`, `Work` 등 필수 경로가 없으면 자동 생성됩니다.
- 설정 파일이 없으면 기본 설정이 생성됩니다.
- 모델이 없으면 다운로드 팝업이 표시됩니다.
- 모델 다운로드는 `ultralytics` 패키지 내장이 아니라 공식 가중치 파일 URL을 직접 받는 방식입니다.

## 5. 기본 단축키
- `` ` `` : 클래스 0 선택
- `1` ~ `9` : 클래스 1 ~ 9 선택
- `W` : 박스 그리기 모드
- `X` : 마스킹 모드
- `A` : 이전 이미지
- `D` : 다음 이미지
- `R` : 현재 이미지의 마지막 박스 삭제
- `T` : 라이트/다크 테마 전환

## 6. 주의사항
- 마스킹은 원본 이미지를 직접 수정합니다.
- `classes.txt`는 반드시 줄마다 하나의 클래스만 작성해야 합니다.
- EXE 실행만으로는 백그라운드 학습/오토 라벨링용 Python 환경이 자동 구성되지 않습니다.
- GPU가 감지되어도 설치된 `torch`가 CUDA를 지원하지 않으면 실제 학습과 추론은 CPU로 전환됩니다.

## 7. EXE 패키징
`Code` 디렉토리에서 아래 명령으로 실행 파일을 빌드할 수 있습니다.

```powershell
python -m PyInstaller --noconfirm --clean --onefile --windowed --name AutoLabeler --distpath .. --workpath .\build --specpath . main.py
```

빌드가 끝나면 `AutoLabeler` 최상위에 `AutoLabeler.exe`가 생성됩니다.
