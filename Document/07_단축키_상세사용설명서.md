# AutoLabeler 단축키 상세 사용설명서

## 작업 모드

- `W`: 박스 그리기. 현재 선택 클래스의 사각형 라벨을 생성합니다.
- `X`: 마스킹. 선택한 사각 영역을 원본 이미지에 검정색으로 반영합니다.
- `E`: 편집. 기존 박스를 이동, 크기 변경, 삭제합니다.
- `Q`: 작업 취소. 현재 작업 모드를 해제합니다.

## 이미지 이동

- `A`: 이전 이미지.
- `D`: 다음 이미지.
- `S`: 화면 맞춤.
- `Go`: 입력한 번호의 이미지로 이동.
- `미작업 찾기`: `[v]`가 아닌 첫 이미지로 이동.

## 삭제

- `R`: 마지막 박스 삭제.
- `Delete`: 현재 이미지와 같은 이름의 라벨 txt 삭제.
- 편집 모드 우클릭: 클릭한 박스 삭제.

## 상태

- `Z`: 빈 이미지 검토. 다른 단축키와 충돌하지 않을 때만 자동 등록.
- `[v]`: 검토 완료.
- `[a]`: 오토 라벨링 완료.
- `[n]`: 미작업.

## 클래스

- `` ` ``: 클래스 0.
- `1`~`9`: 클래스 1~9.
- `0`: 클래스 10. 클래스가 11개 이상일 때만 동작.
- 클래스 11 이상: 클래스 목록에서 선택.
- 색상: 10색 반복.
- 편집 모드 클래스 변경: `E`로 편집 모드 진입 후 `` ` `` 또는 `1`~`9`, `0`을 누른 채 기존 박스 내부를 클릭하면 해당 박스 클래스가 눌린 키의 클래스로 변경됩니다.
- 클래스 키를 누른 상태에서는 커서에 주황색 `Class Change` 안내와 변경 대상 클래스 색상이 표시됩니다.
- 클래스 키를 누르지 않은 상태에서는 기존 편집 기능만 동작합니다.

## 설정

- `T`: 테마 전환.
- `Ctrl+,`: 설정 열기.
- 설정 창: 기능 단축키와 클래스 단축키 수정.

## 비고

- 저장 좌표는 0~1 범위로 보정됩니다.
- 실행 중인 학습/오토 라벨링이 있으면 일부 삭제 기능은 제한됩니다.
