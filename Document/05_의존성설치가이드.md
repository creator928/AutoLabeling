# AutoLabeler 의존성 설치 가이드

## 1. 현재 상태
- 이 프로젝트에는 기본 의존성 목록 파일 [requirements.txt](C:\Users\creat\OneDrive\바탕 화면\LabelingProject\AutoLabeler\Code\requirements.txt)가 있습니다.
- 다만 `torch`, `torchvision`, `torchaudio`는 CPU/GPU 환경에 따라 설치 방식이 달라서 `requirements.txt`에 고정하지 않고 별도 안내로 분리했습니다.
- 프로젝트 루트의 [install_dependency.bat](C:\Users\creat\Desktop\LabelingProject\AutoLabeler\install_dependency.bat)를 실행하면 기본 설치를 한 번에 진행할 수 있습니다.

## 2. 기본 실행용 의존성 설치
권장 방법:

```bat
install_dependency.bat
```

수동 설치:

`Code` 디렉토리에서 아래 명령으로 기본 라이브러리를 설치합니다.

```powershell
pip install -r requirements.txt
```

기본 목록:
- `PyQt6`
- `PyInstaller`
- `ultralytics`
- `opencv-python`
- `onnx`
- `onnxscript`

## 3. GPU 학습용 추가 설치
GPU가 있고, AutoLabeler에서 실제 GPU 학습까지 사용하려면 CUDA 지원 PyTorch를 별도로 설치해야 합니다.

권장 방법:

```bat
install_dependency.bat gpu
```

권장 예시:

```powershell
py -3.10 -m pip install --upgrade --index-url https://download.pytorch.org/whl/cu128 torch torchvision torchaudio
```

ONNX export 의존성도 함께 맞추려면 아래 명령을 추가로 실행합니다.

```powershell
py -3.10 -m pip install --upgrade onnx onnxscript
```

설치 확인:

```powershell
py -3.10 -c "import torch; print(torch.__version__); print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"
```

```powershell
py -3.10 -c "import onnx, onnxscript; print(onnx.__version__); print(onnxscript.__version__)"
```

정상 예시:
- `torch.cuda.is_available()` 가 `True`
- GPU 이름이 출력됨

## 4. CPU 전용 설치
GPU가 없거나 GPU 학습을 사용하지 않을 경우에는 기본 설치만으로도 프로그램 실행과 CPU 학습은 가능합니다.

배치 파일은 기본적으로 CPU 전용 PyTorch까지 함께 설치합니다.
수동 설치가 필요하면 CPU 전용 PyTorch를 다시 설치할 수 있습니다.

```powershell
py -3.10 -m pip install --upgrade torch torchvision torchaudio
```

CPU 전용 환경에서도 ONNX export를 쓰려면 아래 패키지는 필요합니다.

```powershell
py -3.10 -m pip install --upgrade onnx onnxscript
```

## 5. 현재 프로그램 동작 기준
- 프로그램 시작 시 GPU 장치 존재 여부를 확인합니다.
- GPU가 있으면 체크박스는 기본 체크 상태가 됩니다.
- 다만 실제 학습 Python 환경의 `torch`가 CUDA를 지원하지 않으면 학습 시 CPU로 자동 전환됩니다.
- 즉, `GPU 존재`와 `실제 GPU 학습 가능`은 다를 수 있습니다.

- EXE만으로는 외부 Python 학습 환경까지 완전히 대체하지 않습니다.
