# AutoLabeler 요구사항 정의

## 1. 디렉토리 구조
- `AutoLabeler`
- `AutoLabeler/Document`
- `AutoLabeler/Code`
- `AutoLabeler/Data`
- `AutoLabeler/Work`

## 2. 기능 요구사항
### 2.1 실행 및 부트스트랩
- 프로그램 시작 시 필수 하위 디렉토리 존재 여부를 검사합니다.
- 누락된 디렉토리는 실행 파일과 같은 기준 경로에 자동 생성합니다.
- 설정 파일이 없으면 기본 설정을 생성합니다.

### 2.2 모델 관리
- 시작 시 YOLO 모델 파일 존재 여부를 검사합니다.
- 모델이 없으면 다운로드 여부를 묻는 팝업을 표시합니다.
- 기본 권장 모델은 경량형 최신 계열을 사용합니다.
- 다운로드에 실패하거나 사용자가 거부하면 프로그램은 안전하게 종료합니다.

### 2.3 UI/UX
- 회색조 중심의 머테리얼 스타일을 사용합니다.
- 라이트 모드와 다크 모드를 지원합니다.
- 좌측 메뉴 패널은 전체 폭의 약 10% 수준을 차지합니다.
- 좌측에 주요 버튼과 도식화된 단축키 안내를 배치합니다.

### 2.4 작업 폴더 처리
- 사용자가 작업 대상 폴더를 선택할 수 있어야 합니다.
- 폴더 선택 확인 시 `classes.txt` 존재 여부를 검사합니다.
- 파일이 없으면 멀티라인 입력 팝업으로 클래스를 입력받아 생성합니다.
- `classes.txt`는 줄마다 하나의 클래스 이름을 저장합니다.

### 2.5 클래스 및 이미지 표시
- 작업 준비가 끝나면 우측 상단에 `0:Human`, `1:Dog` 형식으로 클래스 목록을 표시합니다.
- 작업 폴더 내 이미지 파일을 이름순으로 정렬해 리스트에 표시합니다.
- 가장 먼저 정렬된 이미지를 자동으로 불러옵니다.

### 2.6 라벨링
- 현재 선택 클래스는 단축키로 변경할 수 있어야 합니다.
- 기본 단축키는 `` ` `` = 클래스 0, `1` = 클래스 1, `2` = 클래스 2 ... 형식입니다.
- 마지막으로 선택한 클래스는 다음 작업에도 유지됩니다.
- `W`로 박스 그리기 모드에 진입합니다.
- 드래그 방식과 클릭-클릭 방식 두 가지 사각형 입력 모드를 지원합니다.
- 클래스별 기본 색상은 다음과 같습니다.
  - 0: green
  - 1: red
  - 2: blue
  - 3: cyan
  - 4: magenta
  - 5: yellow
  - 6: white
  - 7: black
- 라벨은 YOLO 형식 텍스트 파일로 이미지와 같은 이름으로 저장합니다.

### 2.7 이미지 탐색
- `A`는 이전 이미지, `D`는 다음 이미지를 엽니다.
- 첫 이미지에서는 `A`가 동작하지 않아야 합니다.
- 마지막 이미지에서는 `D`가 동작하지 않아야 합니다.

### 2.8 마스킹
- `X`로 마스킹 모드에 진입합니다.
- 사용자가 지정한 사각형 영역을 검은색으로 덮습니다.
- 실제 이미지가 변경되므로 확인 팝업이 필요합니다.
- 취소하면 마스킹 결과는 롤백되어야 합니다.

## 3. 비기능 요구사항
- 모든 소스 코드는 UTF-8 인코딩을 사용합니다.
- 코드 주석은 한국어로 작성합니다.
- 모듈 구조를 분리해 유지보수성을 확보합니다.
- 설정값은 사용자가 편집 가능한 JSON 파일로 저장합니다.
