# AutoLabeler 아키텍처 설계

## 1. 계층 개요
- `main.py`
  - 앱 실행 진입점
- `autolabeler/config.py`
  - 경로 계산, 기본 설정, 설정 저장
- `autolabeler/models.py`
  - 설정값, 라벨 정보, 모델 후보 등 데이터 구조
- `autolabeler/services`
  - 부트스트랩, 작업 폴더 처리, 라벨 저장, 모델 준비
- `autolabeler/ui`
  - 메인 윈도우, 캔버스, 다이얼로그, 테마

## 2. 데이터 흐름
1. 앱 시작
2. 디렉토리/설정 검사
3. 모델 검사
4. 작업 폴더 선택
5. 클래스 로딩 또는 생성
6. 이미지 목록 생성
7. 이미지 선택 시 기존 YOLO 라벨 로딩
8. 캔버스에서 박스 추가/마스킹
9. 라벨 또는 이미지 변경 저장

## 3. 저장 규칙
### 3.1 설정 파일
- 위치: `Data/settings.json`
- 내용: 테마, 단축키, 사각형 입력 방식, 마지막 모델 선택값

### 3.2 모델 파일
- 위치: `Data/models`
- 내용: YOLO 가중치 파일

### 3.3 라벨 파일
- 위치: 각 이미지 파일과 같은 폴더
- 이름: 이미지 이름과 동일, 확장자만 `.txt`
- 형식: YOLO detection 포맷

## 4. 구현 판단
- 자동 라벨링 추론은 실제 YOLO 호출과 UI 동기화가 필요하므로 현재 버전에서는 모델 준비 구조만 먼저 완성합니다.
- 마스킹은 사용자가 의도적으로 원본 이미지를 바꾸는 기능이므로 반드시 확인 절차를 거칩니다.
- 좌측 패널은 짧은 안내와 제어에 집중하고, 우측은 실제 작업 영역으로 사용합니다.
