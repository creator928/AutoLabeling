AutoLabeler 사용설명서

1. 실행
- AutoLabeler.exe를 실행합니다.
- 코드로 실행할 때는 start_autolabeler_source.bat를 실행합니다.
- conda 환경을 지정해 exe를 실행할 때는 start_autolabeler_conda.bat를 실행합니다.

2. 작업 폴더
- 작업 폴더 선택 버튼을 누릅니다.
- 이미지와 classes.txt가 있는 폴더를 선택합니다.
- classes.txt가 없으면 프로그램에서 클래스 목록을 입력해 생성합니다.

3. 기본 라벨링
- 우측 클래스 목록에서 클래스를 선택합니다.
- W: 박스 그리기.
- 마우스로 이미지 위에 박스를 그립니다.
- 작업한 이미지는 자동으로 검토 완료 상태가 됩니다.

4. 편집
- E: 편집 모드.
- 기존 박스를 드래그하면 위치를 이동합니다.
- 박스 꼭짓점을 드래그하면 크기를 변경합니다.
- 편집 모드에서 우클릭하면 해당 박스를 삭제합니다.
- 편집 모드에서 ` 또는 1~9, 0을 누른 채 박스 내부를 클릭하면 해당 박스의 클래스를 변경합니다.
- 이때 커서에 주황색 Class Change 안내와 변경 대상 클래스 색상이 표시됩니다.

5. 마스킹
- X: 마스킹 모드.
- 마스킹할 영역을 드래그합니다.
- 확인하면 원본 이미지에 검정색 영역으로 저장됩니다.

6. 이미지 이동
- A: 이전 이미지.
- D: 다음 이미지.
- S: 화면 맞춤.
- 우측 번호 입력 후 Go: 해당 번호 이미지로 이동.
- 미작업 찾기: [v]가 아닌 첫 이미지로 이동.

7. 삭제
- R: 현재 이미지의 마지막 박스 삭제.
- Delete: 현재 이미지 파일과 라벨 txt를 함께 삭제.

8. 클래스 선택
- `: 클래스 0.
- 1~9: 클래스 1~9.
- 0: 클래스 10. 클래스가 11개 이상일 때만 동작합니다.
- 클래스 11 이상은 우측 클래스 목록에서 선택합니다.

9. 상태 표시
- [v]: 사용자가 검토 완료.
- [a]: 오토 라벨링 완료.
- [n]: 미작업.
- Z: 빈 이미지 검토. 단축키가 비어 있을 때만 동작합니다.

10. 학습과 오토 라벨링
- 백그라운드 학습 진행: 현재 검토된 라벨로 학습합니다.
- 학습 결과 검증: 학습 결과 이미지를 확인합니다.
- Auto Labeling: 학습 결과로 남은 이미지에 자동 라벨을 생성합니다.

11. 주의
- 저장 좌표는 자동으로 0~1 범위로 보정됩니다.
- 학습과 오토 라벨링은 Python, ultralytics, torch 환경이 필요합니다.
- GPU를 사용하려면 CUDA 지원 PyTorch가 설치되어 있어야 합니다.
